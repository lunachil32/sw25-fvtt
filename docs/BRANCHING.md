# ブランチ運用

このリポジトリは `lunachil32/sw25-fvtt` の独立運用フォークです。
本家 `jeannjeann/sw25-fvtt` への貢献・書き込みは目的としません。

## 役割

| ブランチ | 役割 | 取り込む内容 |
| --- | --- | --- |
| `main` | フォークのリリース済み状態。GitHub の既定ブランチ | 検証が完了し、リリースする変更 |
| `develop` | 次回リリースに向けた開発・統合・検証 | 作業ブランチで行った変更 |
| `upstream-sync` | 本家の `main` を追跡する専用ブランチ | `upstream/main` の履歴のみ |
| `<変更者>/<変更名>` の作業ブランチ | 機能追加・対応・リファクタリング・統合検証 | `develop` から分岐した開発内容 |

`upstream-sync` にフォーク独自の変更や運用ドキュメントをコミットしません。
本家の更新を自動的に `main` へマージしません。
作業ブランチの通常のマージ先は `develop` とし、リリース時に検証済みの変更を `main` に反映します。

## 作業ブランチの命名

作業ブランチは `<変更者>/<変更名>` の形式にします。
`<変更者>` には変更を行う人のアカウント名、`<変更名>` には変更内容を表す短い名前を使います。
Codex が作業を代行する場合も、依頼者のアカウント名を使います。

例: `lunachil32/fix-character-sheet`、`lunachil32/fork-readme`

`main`、`develop`、`upstream-sync` は用途を固定したブランチなので、この命名規則の対象外です。
